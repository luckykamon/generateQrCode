# Generate QR Codes

### Présentation
L'objectif de ce projet est de pouvoir générer des QR Codes via une API et une interface web simpliste. Une personnalisation du QrCode avec une image centrée à l'intérieur et une couleur est possible.

### Documentation de l'API
(https://documenter.getpostman.com/view/12914728/2s93ecwAaw)[https://documenter.getpostman.com/view/12914728/2s93ecwAaw]

### Execution du projet

La commande suivante se charge toute seule de l'installation des dépendances
```bash
mvn clean spring-boot:run
```
